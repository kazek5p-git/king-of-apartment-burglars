iPhone audio game

King of Apartment Burglars

A fictional lockpicking audio game designed first for blind players, with a visual door scene for sighted players.

About

King of Apartment Burglars is a fictional game about a new recruit trying to clear a set of increasingly difficult addresses. The current iOS version focuses on abstract lock gameplay, sound cues, timing, training, and VoiceOver-friendly navigation.

The criminal setting is fictional. The app does not teach real burglary and does not encourage breaking the law.

Accessibility

The game is built around audio and clear screen reader behavior. Menus use native iOS controls, the active lock scene relies on sound cues, and the visual layer mirrors the same timing without exposing hidden progress.
